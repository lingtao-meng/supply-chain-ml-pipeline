# 从公开订单样本看懂交付分析

本文选取DataCo公开数据中的订单样本 `67041`。使用现有正式处理函数与训练期历史分布计算，不重新拟合机器学习模型。

## 1. 先分清表格的一行代表什么

这笔订单包含 **4行商品明细**，合计 **10件**，净额 **1073.94美元**。
若按明细行收100美元加急费，会算成 400美元；按一个订单只应收100美元。`src/pipeline.py` 的 `to_order_level` 正是在解决统计单位的问题。

| 明细序号 | 数量 | 明细净额（美元） |
|---|---:|---:|
| 1 | 1 | 347.98 |
| 2 | 1 | 254.98 |
| 3 | 3 | 245.98 |
| 4 | 5 | 225.00 |

合并时数量和净额求和，单位净额为“合计净额÷合计数量”，类别取众数。它不是重新读取某一行就代表整单。

## 2. 标签是预测对象，不能放进输入

公开记录下单日期为 `2017-09-05 15:05:00`，发运日期为 `2017-09-07 15:05:00`，承诺天数为 `2`。
按代码的日期差规则，标签为 **0天**。正数表示相对承诺多用时，0表示相同，负数表示少用时。
这里解释的是公开数据字段，不把发运日期改称签收日期。

`make_features` 生成18列输入：日期派生、类别编码、净额和数量等交互。日期差和事后状态不作为输入。
编码器只从训练区学习类别。输入中的 `total_value` 是合并净额；不能把净额再折扣一次。

## 3. 用训练区历史估计“可能晚多少”

主流程前70%的订单为训练区，这个样本位于最后15%的测试区。只统计训练区Second Class的延迟分布，不用本单答案生成分布。

| 偏差D（天） | 训练期概率 |
|---|---:|
| -2 | 0.000000 |
| -1 | 0.000000 |
| 0 | 0.200134 |
| 1 | 0.199798 |
| 2 | 0.200358 |
| 3 | 0.199126 |
| 4 | 0.200582 |

这些概率加起来为1。PMF就是“每个可能结果各占多少”，不是一个保证会发生的天数。对应 `src/policy.py` 的 `pmf_table`。

## 4. 把概率转换成三个动作的期望成本

先计算 `Σ 概率 × max(D,0)`；加急则计算 `Σ 概率 × max(D−2,0)`。
“Σ”只表示把表里七项相加。再按动作菜单加固定费：

| 动作 | 算法 | 期望成本（美元/单） |
|---|---|---:|
| 不干预 | 200×期望正延迟 | 400.0448 |
| 通知 | 20+200×0.6×期望正延迟 | 260.0269 |
| 加急 | 100+200×期望剩余正延迟 | 220.0582 |

取最小值，本单建议动作是 **express**。对应 `expected_cost_from_pmf` 与 `policy_expected_cost_pmf`。
这是给定动作效果下的计算选择；“减2天”和“罚金乘0.6”是设定，不是由这条记录估计出来的因果效果。

## 5. 评估时才看测试标签

把本单已观测标签0天代入同一公式，三个动作的离线评估成本为：
不干预 **0.00**、通知 **20.00**、加急 **100.00美元**。
期望成本用于提前作选择，代入测试标签后的成本用于评价选择。单个样本的结果不代表整体表现；主表汇总9,863个测试订单。
本单没有出现正延迟，加急后也会产生固定费。事前按群体分布选择的最低期望成本，不保证每条样本的事后成本都最低；这正是需要汇总样本外成本并设置事后成本下界的原因。

## 6. 用现有函数复算

从仓库根目录执行，先按README准备公开CSV：

```python
import numpy as np
from src import pipeline, policy

df = pipeline.to_order_level(pipeline.load_orders('data/DataCoSupplyChainDataset.csv'))
training = df.iloc[:int(len(df) * 0.70)]
table, fallback = policy.pmf_table(training['Shipping Mode'].to_numpy(), training['delay_days'].to_numpy())
costs = policy.expected_cost_from_pmf(table['Second Class'][None, :], penalty=200)
print(costs, np.argmin(costs, axis=1))
```

上述片段复算训练期查表分布与动作选择。完整训练与评估入口为 `scripts/refresh_cost_analysis.py`。
