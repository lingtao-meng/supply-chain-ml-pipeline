## The signal ceiling: shipping mode is the whole model

- A base-rate lookup on `Shipping Mode` alone reaches AUC **0.7803**; the 18-feature model reaches **0.7794** (gap -0.0008).
- Within `Second Class` the AUC is **0.5012** (n=5,395, late rate 80.2%) — no per-order signal.
- Within `Standard Class` the AUC is **0.5008** (n=16,047, late rate 39.7%) — no per-order signal.
- Independence checks inside `Standard Class` (chi-square, Cramér's V): Market p=0.106/V=0.007, Category Name p=1.000/V=0.017, Customer Segment p=0.071/V=0.008, Type p=0.010/V=0.009, order_month p=0.005/V=0.013

The delay is uniform inside each shipping mode (Standard: −2..2, Second: 0..4 at 20% each),
so 0.78 is not a modelling failure — it is the information ceiling of this dataset.

## Headline deltas

- do nothing → pmf: $4,882,200 → $3,058,600 (37.4% lower)
- all express → pmf: $3,346,800 → $3,058,600 (8.6% lower)
- **quantile grid → pmf: $3,258,160 → $3,058,600 (6.1% lower)**
- legacy binary → pmf: $3,358,100 → $3,058,600 (8.9% lower)
- fair binary (same decision layer) → pmf: $3,069,200 → $3,058,600 (0.3% lower)

The v1 README compared the quantile policy against `p50 > 0`, which is a *threshold*
bug, not a model gap: once the binary baseline gets the same expected-cost rule it lands
within 0.35% of the optimum. The real gap is the 3-quantile reconstruction of a 7-atom distribution.
